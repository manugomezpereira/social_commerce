# MVP

## Herramientas&#x20;

### Manychat

* el plan gratis no incluía respuestas de datos estructurados con la IA
* no pude hacer llamadas http a un servidor con el plan gratis&#x20;
* El procesamiento de la respuesta de la llamada del servidor es más complejo y con menos libertad



### make

* No tiene módulo de envío de mensajes privados como Manychat, por lo que no se puede usar directamente para enviar los mensajes privados.

### Costes

#### Openai (Model: GPT-4o-mini)

Paso2: Saber si es transaccional o no el comentario = $0.0001



* Procesar 40 comentarios = 0.004€

#### Manychat

* Estimamos que a un microinfluencer con 10k seguidores le llegan 200 comentarios mensuales.
* Del total de comentarios, 20%(40 comentarios) son transaccionales.
* Plan mensual de 15€/mensuales



#### Make

* Plan mensual 9€/mensuales para 10k operaciones.



#### Recuperador de producto (Paso6)

* Server 10€/mensuales



| **Elemento**                           | **Descripción**                                                              | **Coste mensual estimado (€)** |
| -------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------ |
| **OpenAI (GPT-4o-mini)**               | Procesamiento de 40 comentarios transaccionales a 0,0001 USD c/u (\~0,004 €) | 0,004                          |
| **Manychat**                           | Plan mensual básico para automatización y respuesta a comentarios            | 15,00                          |
| **Make (Integromat)**                  | Plan para hasta 10k operaciones                                              | 9,00                           |
| **Servidor (Recuperador de producto)** | Hosting o servidor necesario para el paso 6                                  | 10,00                          |
|                                        |                                                                              |                                |
| **TOTAL MENSUAL ESTIMADO**             |                                                                              | **34,00 €**                    |

De los 40 comentarios transaccionales supongamos que se trabajaron los 40 con envíos de mensajes y un 10% convirtió (4)

* Si hay 4 conversiones a ticket medio de 50€ y comisión de 7% = 14€ comisión.
